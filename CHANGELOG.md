# Changelog

All notable changes to the `geiserx.genieacs` collection.

## 0.1.1 (2026-10-13)

Docs-only release. The plugins and modules are unchanged from 0.1.0.

- README rewritten: short overview and quick start, with the details moved into `docs/` (getting started, configuration, usage).
- New banner and social preview.
- `galaxy.yml` now sets `documentation:`, so Galaxy links to the getting started guide.
- The package no longer ships repo-only files (agent instructions, issue tracker config and hooks, CodeRabbit config).
- Related projects point at genieacs-container and genieacs-sim-container (the renamed genieacs-sim-docker).

## 0.1.0 (2026-04-03)

First release.

- `geiserx.genieacs.genieacs` dynamic inventory plugin.
- `genieacs_task`, `genieacs_preset` and `genieacs_provision` modules.
